CSS Grid Layout

Flexbox arranges items in a single row or column, making alignment, spacing, and ordering quick and flexible perfect for headers, nav bars, and small UI components on websites.

CSS Grid controls rows and columns together, so it’s ideal for building responsive page layouts and galleries.
